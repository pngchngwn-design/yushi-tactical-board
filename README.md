# 于氏珠宝足球队专用战术板

赛前排兵布阵 · 阵型智库 · 对手盯防推演。零依赖纯本地网页，双击即用。

## 快速开始

无需安装任何软件：

1. **电脑使用**：双击 `index.html`，用 Edge/Chrome 等浏览器打开即可。
2. **手机使用**：把整个 `yushi-tactical-board` 文件夹（含 index.html、css、js、assets）发送到手机，用手机浏览器打开 index.html 即可。
3. **可存桌面**：把整个文件夹复制/压缩后放到桌面或发到群里，任何设备解压后双击即开。
4. **可打印**：页面右上工具栏点「打印」，只打印球场布阵图。
5. **可导出图片**：点「导出图片发群」，自动生成含球场布阵+对手情报的整图 PNG，可直接发微信群。

## 功能

- 16 名队员真实照片头像，从左侧队员池**拖拽上场**
- **队员管理**：工具栏「队员管理」入口，适用于任何比赛——新增队员（姓名/号码/照片）、改名字改号码、换照片、删除、一键恢复默认16人名单；修改保存在当前设备浏览器里
- **五人制 5 套 / 八人制 8 套 / 十一人制 9 套**共 22 套阵型，一键切换
- 每套阵型含：优缺点、适合什么样的球队、五大联赛代表俱乐部、破解思路
- 「随机微调」：在阵型基础上随机扰动站位，模拟临场变化
- 「+对方红标」：在球场上标注对方核心球员，制定盯防
- 对手情报栏（对手队名/对方核心/对方战术/我方对策），自动保存
- 所有布阵与情报自动存浏览器本地，下次打开接着用
- 「决赛锦囊」：八人制决赛实战要点

## 目录结构

```
yushi-tactical-board/
├── index.html          # 入口页面
├── css/style.css       # 样式
├── js/data.js          # 队员名册 + 22套阵型战术库
├── js/images.js        # 队员头像base64（保证离线导出图片可用）
├── js/app.js           # 交互逻辑
├── assets/players/     # 队员头像原图
└── README.md
```

## 技术栈

纯 HTML + CSS + 原生 JavaScript，无任何依赖、无网络请求，完全离线可用。

## 部署为公网链接（可选）

把整个文件夹部署到 GitHub Pages / Netlify 等静态托管后，任何联网设备可访问。
注意：部署后队员照片对任何拿到链接的人可见；队员管理里的上传数据存在各自设备的浏览器中，不会同步到其他设备。
